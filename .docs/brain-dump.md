Projeto lista de Streamers

O projeto consiste em acessar a API do Chess.com e exibir uma lista de streamers que estiverem online.

- o Conteúdo tem que ficar centralizado na tela, com 02 cards lado a lado.
- Cada card deve exibir informações dos streamers que estiverem online, mostrando a foto de perfil, link de acesso pra assistir no twitch.
- O card deve mostrar uma bola vermelha indicando que aquele streamer está ao vivo.

- O link para a requisição da APi é: https://api.chess.com/pub/streamers

- Os cards podem ser brancos, mas com um fundo escuro pra dar um realce.

- DEve usar react e seus recursos, como useState, useEfect e clean. 

- crie um campo de busca, para que o usuário realize a busca. Crie um state, pra qundo a busca não encontrar conteúdo.
